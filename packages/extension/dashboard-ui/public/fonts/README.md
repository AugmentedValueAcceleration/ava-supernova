# Bundled wordmark fonts

Curated fonts for typesetting brand-name **wordmarks** in the logo generator
(real type, never generated pixels). Each is a single static weight chosen to
read well as a logo. opentype.js reads these to convert a wordmark to SVG paths.

**Every family here is licensed under the SIL Open Font License 1.1 (OFL)** —
free for commercial use *including creating and selling logos*, and free to
bundle with this app. Per-family licences are in `licenses/`. Sourced from Google
Fonts (static weights via google-webfonts-helper).
