# Permission Modes

Control how much Ava can do without asking.

| Mode | File Edits | Shell Commands |
|---|---|---|
| **Strict** | Ask every time | Ask every time |
| **Balanced** | Auto-approve | Ask every time |
| **Autonomous** | Auto-approve | Auto-approve |

**Strict** is the default and recommended starting point. You can always upgrade later.

Plans and questions from Ava always require your approval, regardless of mode.
