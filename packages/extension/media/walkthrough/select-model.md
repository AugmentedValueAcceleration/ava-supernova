# Choose Your Model

Pick the model that fits your workflow. Every model runs on your own key — the fleets need the keys their models use, and a single model needs only its own provider's key.

| Model | Best For |
|---|---|
| **Qwen 3.8 Flash** | Fast and cheap for everyday turns — 1M context, reads images and video |
| **Qwen 3.7 Plus** | Agentic coding, 1M context, vision |
| **Qwen 4 Max** | Alibaba's flagship — deep planning and analysis, 1M context |
| **DeepSeek V4.1 Flash** | Best value — fast general-purpose coding, 1M context, reads images (MIT open-weight) |
| **Kimi K3.1 Pro** | Agentic coding, strong tool calling, 1M context, vision |
| **GLM-5.3** | Open-weights, 1M context, thinking (text only) |
| **GLM-5.3 Flash** | Open-weights, 1M context, reads images and video |
| **Mistral Large 4** | EU flagship, open-weight, 1M context, vision |
| **Hunyuan Hy4 Flash** | Very cheap, 1M context, vision |

You can switch models any time from the dropdown in the chat header.
