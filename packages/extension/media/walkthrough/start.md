# Start Coding with Ava

You're all set. Here's what Ava can do:

## Six Modes — States of Thought

- **Work** (`>>`) — Builder mindset. Full agent with all 63 tools. Ava reads, writes, searches, and executes.
- **Plan** (`::`) — Architect mindset. Read-only analysis. Ava reads your code and creates plans without modifying anything.
- **Chat** (`..`) — Friend mindset. Personal conversation with memory, search, and journal. No work tools.
- **Teach** (`??`) — Tutor mindset. Ava becomes your personal teacher. Full toolkit, but guides instead of doing.
- **Security** (`!!`) — Auditor mindset. AI-powered OWASP-aligned security audit.
- **Brainstorm** (`**`) — Ideation mindset. Business ideas, feature brainstorming, creative problem solving.

## Tips

- Use **Work** mode for building features, fixing bugs, and refactoring
- Use **Teach** mode to learn anything — say "teach me Python" and Ava builds a personalised curriculum
- Use **Chat** mode when you just want to talk — Ava remembers your conversations
- Use **Security** mode to scan your project for vulnerabilities — just click `!!` and send
- Create `.ava/instructions.md` in your project root to give Ava persistent context
- Attach images for models that support vision (Claude, GLM-5, Kimi K2.5, Qwen 3.5 Plus, Mistral Large)
- Your conversations are auto-saved per project — resume anytime from Chat History
