# Start Coding with Ava

You're all set. Here's what Ava can do:

## Four Modes

- **Code** (`>>`) — Full agent with all 13 tools. Ava reads, writes, searches, and executes.
- **Plan** (`::`) — Read-only analysis. Ava reads your code and creates plans without modifying anything.
- **Chat** (`..`) — Conversation only. No tools, just discussion.
- **Security** (`!!`) — AI-powered OWASP-aligned security audit. Scans your project for vulnerabilities.

## Tips

- Use **Code** mode for building features, fixing bugs, and refactoring
- Use **Security** mode to scan your project for vulnerabilities — just click `!!` and send
- Create `.ava/instructions.md` in your project root to give Ava persistent context
- Attach images for models that support vision (Qwen 3.5 Plus, GLM-5)
- Your conversations are auto-saved per project — resume anytime from Chat History
- Connect your Ava platform account via the Dashboard for managed API access
